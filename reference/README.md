  `wifi-qcom-ac`

- 16 MB flash limits on qcom-ac CAPs
- Neighbor-discovery `tx-only` workaround on qcom-ac

[templates/soho/DESIGN.md](../templates/soho/DESIGN.md) and
[docs/conventions.md](../docs/conventions.md). Put a note here when something

doc once a site has confirmed it.
