# Scripts

Shared RouterOS scripts that are not tied to one template family or one site.

Nothing is checked in yet. Add a snippet here when more than one template needs it (upgrade helpers, backup reminders, common checks). Keep the same token rules as the templates: `SITE_*` and `CHANGE_ME_*` in git, real values only on the device. See [docs/conventions.md](../docs/conventions.md).
